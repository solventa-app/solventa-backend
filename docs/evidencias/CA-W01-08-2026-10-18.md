# Evidencia CA-W01-08 — Ciclo de vida, titularidad, vencimiento y revocación del consentimiento (< 5 min)

- **Fecha:** 2026-10-18
- **Criterio de aceptación y normativa:** CA-W01-08, Ley 1581 de 2012 (Habeas Data) y Circular Externa 004/2024 de la SFC (Open Finance).
- **Requisitos verificados:**
  1. El consentimiento queda ligado al titular (hash opaco del documento de identidad, nunca el documento en claro) y registra `tipoDato`, `fuenteDatos`, `canal`, `otorgadoEn`, `venceEn` (30 días, decisión 23) y `estado` (`VIGENTE`, `REVOCADO`, `VENCIDO`).
  2. `solicitarOferta` exige que el consentimiento pertenezca al mismo titular del documento cotizado y que esté vigente (`revocado_en IS NULL AND now() < vence_en`).
  3. La consulta a Open Finance a través del ACL Worker envía `consentimiento_id` y `finalidad`, y el proveedor responde `403 Forbidden` si faltan.
  4. Tras `revocarConsentimiento`, cualquier consulta nueva se rechaza de inmediato (**0 s < 5 min**) con `ErrorOferta` (`motivo: CONSENTIMIENTO_NO_VIGENTE`, `puedeReintentar: false`), el `consolidador-fuentes` aborta cualquier reconciliación diferida de ese consentimiento y la caché del titular expira/se invalida en **< 5 min** (`CACHE_TTL_SEGUNDOS=300`).

## 1. Comandos ejecutados

```bash
# 1. Pruebas unitarias y de integración en AUTH, BFF, ACL Worker y stub-open-finance:
pytest services/auth/tests services/bff/tests services/acl-worker/tests stubs/open-finance/tests

# 2. Prueba de humo de punta a punta a través del API Gateway:
BFF_URL=http://localhost:8080 python3 scripts/humo_bff.py
```
